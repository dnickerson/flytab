Feature B — MEA on Airway Pills

MEA from NASR bundle (mea_ft / mea_gnss_ft). Only airway pills show MEA — DIRECT legs have none. Async lookup runs after any route change.

Feature C — Mixing Height in Altitude Optimizer

MOS data already fetched by wx-briefing via flywhere.app/mos?ids=…. Reuse the same endpoint. mix_ht field in MOS periods → show average mixing height along route at departure time. Retry once on 503.

Data source: Same MOS endpoint as wx-briefing. Fetch on popup open if not already cached. Retry once after 2s on 503 (server cold start).

Mixing height: Average of mix_ht from each airport's MOS period nearest to departure time. If MOS unavailable, column shows "—" with note "MOS unavailable".

Labels: "⚠ in BL" (boundary layer, orange) if altitude ≤ mix_ht. "✓ above" (green) if altitude > mix_ht. No label if MOS not loaded.
