How It Works

  • Computation: Calls recomputeLegs() 5× with the same route and winds, one per altitude level. Pure JS — completes in <5ms.
  • Triggered: When popup opens (if route + winds exist), and whenever winds or route changes while popup is open.
  • Ceiling cutoff: 18,000 ft always grayed — O-360 practical ceiling ~14,000 ft. Row shown for completeness but no data.
  • Current selection: Row matching _cruiseAltFt gets left blue bar + bold. Dropdown change → table re-highlights instantly.
  • MOS column ready: When Feature C (mixing height) is implemented, a MIX column slots in between GAL and right edge — table stays same structure.
