What actions appear in the GPS diagnostic panel?

Panel opens when pilot taps the red GPS pill. Showing 3 approaches to the fix buttons.

⚠ GPS UNAVAILABLE
08:42:01 gps_source = internal
08:42:11 TIMEOUT (code 3)
08:42:21 TIMEOUT (code 3)
08:42:21 Stratux fix=2 sats=8/12
✓ USE STRATUX GPS (RECOMMENDED)
Stratux is connected with GPS lock

A — One Smart Fix Button

Analyzes the situation and shows one recommended action. "Stratux is connected with fix — switch to it." No choices to make under stress.

⚠ GPS UNAVAILABLE
08:42:01 gps_source = internal
08:42:11 TIMEOUT (code 3)
08:42:21 Stratux fix=2 sats=8/12
USE STRATUX GPS
USE DEVICE GPS
AUTO (fallback)

B — All GPS Source Buttons

Shows all three GPS source options directly in the panel. Pilot picks without going to Settings. More control, more cognitive load in a stressful moment.

⚠ GPS UNAVAILABLE
08:42:01 gps_source = internal
08:42:11 TIMEOUT (code 3)
08:42:21 Stratux fix=2 sats=8/12
CAUSE: GPS source is set to Device GPS but this device has no GPS hardware. Switch source to Stratux.
FIX: SWITCH TO STRATUX
SETTINGS

C — Diagnosis + Fix + Settings

Plain-English cause ("GPS source is 'internal' but device has no GPS hardware"), one recommended fix button, and a Settings escape hatch.

All options also auto-collapse the panel and restore ownship when GPS is resolved.
