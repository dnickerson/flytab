Route Display Redesign — 3 Approaches

Three independent decisions are bundled here: draggable sheet height, WPT column fix, and landscape compact mode. The approaches differ mainly in how the drag behavior works.

A

Drag-to-snap (Recommended)

The handle bar is draggable. On release it snaps to the nearest of 3 stops: closed / 3-row (~80px) / 7-row (~185px). Tap the handle to cycle the same 3 stops. Familiar, predictable, no accidental in-between states.

WPT column: table-layout: fixed + <colgroup> with explicit widths pins every column. Fuel-stop row can't stretch WPT.

Compact mode: TMR tab becomes a ⊞/⊟ toggle. When active: hides #instrumentStrip and .route-table-sheet, reclaims ~130px. State saved to localStorage. Auto-restores on portrait rotation.

Pros

  • Simple mental model — 3 stops, no guessing
  • Reliable in turbulence / fat fingers
  • Easy to implement

Cons

  • Can't show exactly N rows between stops
B

Free drag (continuous)

Drag the handle to any height. A small "N rows visible" badge appears during drag. On release, height is remembered. No snap stops — exact height is preserved.

WPT column: Same fixed-layout fix as A.

Compact mode: Same TMR-toggle as A.

Pros

  • Precise control — show exactly the rows you want
  • Pilots with long routes can tune it

Cons

  • No "closed" snap — hard to fully dismiss
  • Harder to reliably hit closed state one-handed
  • Remembering exact px height adds complexity
C

Drag-to-snap with more stops

Like A but with 5 stops: closed / 2 rows / 4 rows / 7 rows / full (~50vh). Tap still cycles. Drag snaps to nearest. Gives finer row control without free-drag complexity.

WPT column: Same fixed-layout fix as A.

Compact mode: Same TMR-toggle as A.

Pros

  • More granularity than 3-stop
  • Still snaps — reliable in cockpit

Cons

  • 5 tap-cycles is tedious — user would mostly drag
  • More height math to get row stops right
Common to all approaches
  • WPT column width fix via table-layout: fixed — same regardless of drag model
  • Compact landscape toggle replaces TMR tab button
  • Compact mode hides both #instrumentStrip and .route-table-sheet
  • Compact state persists in localStorage; auto-clears on portrait rotation
