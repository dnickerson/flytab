Sticky Valve Warning
WHAT IT MEANS:
One cylinder's EGT is significantly lower than others during warmup. May indicate a sticky exhaust valve ("morning sickness").

Detection:

  • Monitored first 10 minutes after start
  • Triggers if one EGT < 50% of others for 30+ seconds
  • Auto-clears if cylinder recovers

What to do:

  1. Note the affected cylinder
  2. Monitor if it clears as engine warms
  3. If persists: Land and have mechanic inspect
  4. Reference: Lycoming SB 388C
WARNING: Sticky valves get worse, not better. If this warning appears repeatedly, have valve-to-guide clearance checked before next flight.
Emergency Quick Reference
HIGH CHT (>400°F):
Enrich → Reduce Power → Increase Speed → Open Cowl Flaps
ENGINE ROUGHNESS:
Check mags → Check mixture → Check carb heat → Check fuel
STICKY VALVE ALERT:
Note cylinder → Monitor temps → Land when practical → Get inspection
LOW OIL PRESSURE:
Reduce power → Prepare for precautionary landing → Monitor temps
Leaning Procedure
  1. Set cruise power (65% or less)
  2. Slowly lean mixture
  3. Watch EGTs rise toward peak
  4. For LOP: Continue past peak until 50°F below
  5. For ROP: Stop 100°F before peak
  6. Monitor: All EGTs should be within 50°F of each other
Carb Icing Risk

Watch Carb Temp when:

  • OAT between 20-70°F
  • High humidity or visible moisture
  • Reduced power settings

If Carb Temp dropping toward 32°F:

  • Apply carb heat
  • Expect RPM drop then rise as ice clears

Fuel Tracking

The fuel tracker integrates fuel flow over time to track remaining fuel.

Fuel Display

REMAININGCurrent fuel in tanks (gallons)
USED (FLIGHT)Fuel consumed this flight (resets on engine start)
ENDURANCEEstimated flight time remaining (H:MM)
RANGEEstimated range in nautical miles

How Calculations Work

Fuel Remaining:

Remaining = Previous Remaining − (Fuel Flow × Time Elapsed)

Fuel flow (GPH) is integrated over time using EDM timestamps (1/64 second precision). Each data sample (~4 Hz) calculates fuel consumed since last sample.

Flight Fuel Used:

Used = Σ (Fuel Flow × dt) since engine start

Resets to zero when engine starts (RPM > 500). Accumulates all fuel consumed during the flight.

Endurance:

Endurance (hours) = Fuel Remaining ÷ Avg Fuel Flow

Uses rolling 5-minute average of fuel flow during cruise. If not in cruise, defaults to 8.0 GPH estimate.

Range:

Range (nm) = Fuel Remaining × (Ground Speed ÷ Fuel Flow)

Uses actual ground speed from Stratux GPS and average cruise fuel flow. Simplified: Range = Fuel Remaining × nm/gal

Cruise Efficiency (nm/gal):

nm/gal = Ground Speed (kts) ÷ Fuel Flow (GPH)

Calculated from 5-minute rolling average during cruise conditions (RPM 2000-2600, MP 18-26", GS > 80 kts).

CSV Flight Recording

Record flight data directly to your iPad for later analysis in spreadsheets.

Recording Controls

RECStart/Stop recording manually
CSVDownload recorded data as CSV file
CLRClear recorded data

Recording Behavior

  • Auto-start: Recording begins automatically when RPM > 500
  • Persistence: Data saved to browser localStorage (survives refresh/close)
  • Capacity: 7200 points (~2 hours at 1 point/second)
  • Auto-export: CSV downloads automatically when capacity reached

CSV Data (41 columns)

Includes all engine parameters plus GPS/attitude data:

  • Engine: RPM, MAP, Oil Temp/Press, Fuel Flow, Volts, Amps, Carb Temp
  • Cylinders: EGT 1-4, CHT 1-4, spreads, max EGT
  • Fuel: Fuel Pressure, Gallons Remaining, Tank Levels
  • GPS: Latitude, Longitude, Altitude, Ground Speed, Course
  • Attitude: Bank, Pitch, Vertical G-load
  • Calculated: Percent Power, ROP/LOP Mode, BSFC

K-Factor Calibration

The K-factor calibrates the EI FT-60 Red Cube fuel flow sensor for accuracy.

How It Works

  1. System tracks actual fuel added (from pump)
  2. Compares to computed fuel used (from flow sensor)
  3. After 30+ gallons, calculates suggested K-factor adjustment
K-factor Ratio = Computed Used ÷ Actual Added
Suggested K = Current K × Ratio

Calibration API

/api/fuel/calibrationView calibration status
/api/fuel/calibration/resetStart new calibration period
/api/fuel/calibration/appliedRecord K-factor applied to Dynon
DEFAULT K-FACTOR: 68000
Adjust in Dynon EMS settings based on calibration recommendations.
